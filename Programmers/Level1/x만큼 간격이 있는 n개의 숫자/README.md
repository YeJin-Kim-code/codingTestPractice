# [Programmers] x만큼 간격이 있는 n개의 숫자 (Python)

## 📝 문제 설명
정수 `x`와 자연수 `n`을 입력 받아, `x`부터 시작해 `x`씩 증가하는 숫자를 `n`개 지니는 리스트를 리턴하는 함수를 완성하는 문제입니다.

- **제한 조건**:
  - `x`는 -10000000 이상, 10000000 이하인 정수
  - `n`은 1000 이하인 자연수

---

## 💡 풀이 접근 방식
파이썬의 **리스트 컴프리헨션(List Comprehension)**과 반복 범위를 지정하는 **`range()`** 함수를 조합하여 해결했습니다.

1. **반복 횟수 제어**: `range(1, n + 1)`을 사용하여 1부터 `n`까지 총 `n`번 반복하도록 설정합니다.
2. **값 계산**: 반복문이 도는 동안 순서대로 `x * 1`, `x * 2`, ... `x * n` 구조로 곱 연산을 수행하여 `x`씩 누적 증가하는 효과를 냅니다.
3. **리스트 생성**: 계산된 값들을 리스트 컴프리헨션 문법으로 묶어 하나의 결과 배열로 즉시 반환합니다.

---

## 💻 코드 구현

```python
def solution(x, n):
    # 1부터 n까지 순서대로 x를 곱한 값들을 리스트로 반환
    return [x * i for i in range(1, n + 1)]
```

---

## 🧠 배운 점 (Retrospective)
- 증감 연산자(`++`)가 없는 파이썬 특성에 맞춰 `range()` 범위 지정을 통해 인덱스를 다루는 직관적인 반복 설계 방식을 다시 정립했습니다.
- 여러 줄의 반복 루프와 `append()` 함수를 사용하는 대신, 리스트 컴프리헨션을 사용하여 가독성과 연산 속도를 모두 높이는 파이써닉(Pythonic)한 코드 작성의 중요성을 배웠습니다.
